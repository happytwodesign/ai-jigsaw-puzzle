LaCrema Demo Hub

One-click demo scenarios, the full puzzle catalog, and the analytics test data — all driving the real app. Scripts for each scenario live in USE-CASES.md.

Fixtures are fetched with fetch(), so serve the repo over HTTP: python3 -m http.server 8000 then open http://localhost:8000/demo/. Opening the file directly (file://) will not work.
